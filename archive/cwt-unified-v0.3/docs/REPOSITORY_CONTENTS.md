# Project content index and evidence states

## Canonical code
- `src/cwt_unified/`: active v0.3 forecasting, ingestion, data validation, sentiment, chart, and reporting modules.
- `tests/`: offline reproducibility and leakage checks.
- `.github/workflows/tests.yml`: GitHub Actions Python test matrix.
- `examples/`: redacted configuration examples only.

## Instructions and verification
- `README.md`: definitive commands and limitations.
- `DATA_SETUP_AND_TASKS.md`: data access and readiness checklist.
- `VALIDATION_STATUS.md`: locally tested vs live unverified boundaries.
- `docs/IMPLEMENTATION_SPEC.md`: modeling and architecture.
- `docs/COMPARATIVE_ARCHITECTURE_AND_REA.md`: external systems review.
- `docs/REVIEW_HANDOFF.md`: independent audit instructions.
- `docs/audits/`: prior methodology/data/repository investigations retained as dated opinions; verify before acting on historical provider claims.
- `archive/legacy-prototypes/`: old stage ZIPs, not canonical code, not publication-ready.

## What is deliberately absent
No real X posts, no real completed 180-day dataset, no credentials, no paid provider tokens, no secret values, no broker trade execution, no verified out-of-sample profit results, and no synthetic results presented as market facts.

## Evidence statement
24 local unit tests are known to have passed on 2026-11-15. This is not a live external-data integration test. Current repo access and GitHub publication must be confirmed separately.
