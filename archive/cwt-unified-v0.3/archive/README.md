# Historical research snapshots

These ZIP files are previous generated coding stages retained only for transparent provenance.

**Do not install or execute these archives as the canonical project.** Use the `src/` tree in the repository root instead. Earlier iterations can contain retired assumptions or incomplete controls. Each archive must be independently evaluated before reuse.

No real-market forecast or verified X dataset is included in these archives. The repository intentionally excludes private tokens, proprietary datasets, synthetic research demos and broker credentials.
